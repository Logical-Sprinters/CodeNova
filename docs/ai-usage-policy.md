# Responsible AI and AI Usage

- AI proposes; a human reviewer approves. Creators cannot approve their own work.
- Findings must cite an active, versioned rule and supporting evidence.
- Abstain and escalate on conflicting or expired rules; never guess.
- Validate model output against strict shared schemas before using it.
- Send only the draft text and relevant active rules. Record redaction and
  retention details in a processing receipt.
- Use fictional TaskFlow content in public demos.
