# Security Policy

Do not report security vulnerabilities in public issues. The project is still a
scaffold and does not yet have a monitored security contact; do not send
sensitive reports until the maintainers publish one.

See [`docs/security-access.md`](docs/security-access.md) for the current access,
privacy, and security requirements, and
[`docs/threat-model.md`](docs/threat-model.md) for the initial threat inventory.

Never commit credentials, production data, or client artwork. Do not use the
current scaffold or database schema with real client data.
